## ✨ Features

- 🔹 **Background script** to handle extension lifecycle events  
- 🔹 **Content script** for interacting with web pages  
- 🔹 **Popup UI** with HTML, CSS, and JS  
- 🔹 **Utility functions** in `utils.js` for modular development  
- 🔹 Clean, modular project setup
